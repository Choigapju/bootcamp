# 부트캠프 지원서 평가 시스템

부트캠프 지원서를 자동으로 분석하고 평가하는 웹 서비스입니다. 머신러닝을 사용하여 지원자의 합격 가능성을 예측하고, 다양한 분석 결과를 제공합니다.

## 주요 기능

- **모델 훈련**: 기존 지원자 데이터를 기반으로 평가 모델 훈련
- **CSV 일괄 평가**: 여러 지원서가 포함된 CSV 파일 일괄 평가
- **단일 텍스트 평가**: 개별 지원서 텍스트 즉시 평가
- **결과 시각화**: 점수 분포 및 주요 특성 시각화
- **상세 분석**: 지원서별 상세 분석 및 평가 제공

## 설치 방법

### 요구 사항

- Python 3.8 이상
- pip (패키지 관리자)

### 설치 단계

1. 저장소 클론 또는 다운로드:
   ```
   git clone https://github.com/yourusername/bootcamp-evaluator.git
   cd bootcamp-evaluator
   ```

2. 가상 환경 생성 및 활성화:
   ```
   # macOS/Linux
   python3 -m venv venv
   source venv/bin/activate
   
   # Windows
   python -m venv venv
   venv\Scripts\activate
   ```

3. 필요한 패키지 설치:
   ```
   pip install -r requirements.txt
   ```

## 실행 방법

1. Flask 애플리케이션 실행:
   ```
   python app.py
   ```

2. 웹 브라우저에서 접속:
   ```
   http://127.0.0.1:5000/
   ```

## 사용 방법

### 1. 모델 훈련

1. 홈 화면에서 '모델 훈련' 버튼 클릭
2. CSV 훈련 데이터 파일 업로드 (`text` 및 `employment` 컬럼 필요)
3. 모델 훈련 결과 및 성능 지표 확인

### 2. CSV 파일 평가

1. 홈 화면에서 'CSV 파일 평가' 버튼 클릭
2. 지원자 정보가 포함된 CSV 파일 업로드
3. 상태 컬럼 및 텍스트 컬럼 이름 지정 (선택사항)
4. 평가 결과 확인 및 다운로드

### 3. 텍스트 평가

1. 홈 화면에서 '텍스트 평가' 버튼 클릭
2. 지원서 텍스트 입력
3. 즉시 평가 결과 확인

## 데이터 형식

### 훈련 데이터 CSV 형식
```
text,employment
"안녕하세요. 저는 프로그래밍에 관심이 많은 지원자입니다. 자바와 파이썬을 주로 사용합니다.",success
"코딩을 배우고 싶어서 지원합니다.",fail
```

### 평가용 CSV 형식
```
가입 이름,가입 이메일,합불상태,지원동기,프로젝트경험
홍길동,hong@example.com,검토전,"안녕하세요. 저는 프로그래밍에 관심이 많은 지원자입니다.","자바 프로젝트를 진행한 경험이 있습니다."
```
